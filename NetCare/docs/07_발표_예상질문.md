# NetCare 발표 예상 질문과 답변

> 기준: 최종 발표자료 v2에서 확인되는 내용만 사용했습니다. PPT에 근거가 없는 세부 기준이나 동작은 추정하지 않고, 자료에서 확인되지 않는다고 표시했습니다.

## 진단 근거와 기준

### 1. NetCare는 패킷에서 어떤 근거를 찾아 원인을 판단하나요?

PPT에서는 TCP 연결의 SYN → SYN-ACK → ACK 흐름과 핸드셰이크 완료율을 근거의 예로 설명합니다. 다운로드 사례에서는 역방향 ACK 비율과 EWMA 기준선 대비 급증 점수도 함께 봅니다. 다만 여러 근거가 특정 원인을 확정하는 세부 판정 로직까지는 발표자료에 나오지 않습니다. 따라서 발표에서 설명 가능한 범위는 이상 신호와 관련 근거를 제시한다는 데까지입니다. (6~9장)

### 2. 연결 미완료를 이상으로 판단하는 기준이나 임계값은 무엇인가요?

PPT는 마지막 ACK가 없으면 연결 미완료일 수 있다고 설명하고, SYN-ACK만 세지 않고 핸드셰이크 완료율을 본다고 합니다. 하지만 이상으로 분류하는 수치 임계값이나 집계 구간은 제시하지 않습니다. (7장)

### 3. 다운로드 사례의 ACK 비율 0.19와 z=7.51은 각각 어떤 판단에 쓰였나요?

PPT에서는 역방향 ACK 비율 0.19를 양방향 다운로드 맥락을 반영하는 데 사용해 정상 다운로드를 공격으로 단정하지 않도록 조정했다고 설명합니다. z=7.51은 EWMA 기준선과 비교한 트래픽 급증 신호로 제시되어, 다운로드 오탐을 줄이면서 급증 자체는 별도 진단으로 남깁니다. 막대그래프는 초별 실제 측정값이 아닌 개념도라고 명시되어 있습니다. (8장)

## 화면과 조치 범위

### 4. 진단 화면의 IP와 근거는 실제 캡처에서도 같은 방식으로 제공되나요?

PPT는 진단 화면 예시가 합성 테스트 데이터라고 밝힙니다. 별도로 Windows에서 Npcap Ethernet 실시간 캡처와 패킷 수신은 확인했다고 설명하지만, 그 실제 캡처 결과가 진단 화면에 같은 방식으로 연결되는지는 발표자료만으로 확인할 수 없습니다. (9장, 13장)

### 5. 사용자가 승인하면 실제로 어떤 방화벽 규칙이 추가되고, 차단 영향은 어떻게 확인하나요?

승인 화면은 대상 IP와 방화벽 규칙, 해당 IP의 서비스 통신이 차단될 수 있다는 영향을 보여주도록 설명되어 있습니다. 하지만 화면은 UI 테스트 예시이며 실제 OS 방화벽 변경의 증거가 아니라고 명시합니다. 실제 규칙의 상세 내용과 적용 결과를 확인하는 방법은 PPT에 제시되지 않습니다. (10장)

### 6. Windows 방화벽 적용과 롤백이 검증되지 않았다면, 현재 ‘해결’은 어디까지 구현된 건가요?

PPT에 따르면 조치 전 기준 측정, 사용자 승인, 재측정, NetCare 규칙 되돌리기의 흐름은 구현되어 있지만 Windows OS 방화벽에 실제 적용하고 롤백하는 동작은 아직 검증되지 않았습니다. 따라서 발표에서 확인된 해결 범위는 사용자가 조치 내용을 검토하고 승인하는 흐름까지이며, 실제 Windows 방화벽 차단과 복구가 검증됐다고 말할 수는 없습니다. (10~11장, 14장)

## 검증 범위

### 7. 90,316개 패킷과 누락 0건은 어떤 시간과 트래픽 조건에서 측정한 결과인가요?

PPT는 관리자 권한에서 Npcap Ethernet 실시간 캡처를 확인했고, 확인 당시 누적 패킷 수가 90,316개이며 누락은 0건이었다고 합니다. 측정 시간과 구체적인 트래픽 조건은 발표자료에 나오지 않습니다. 또한 90,316은 처리율이 아니라 확인 시점의 누적 패킷 수라고 명시되어 있습니다. (13장)

### 8. UI 테스트 71건과 pytest 55건은 각각 어떤 기능을 검증했고, 아직 검증되지 않은 동작은 무엇인가요?

PPT는 Windows UI E2E 71/71, API를 제외한 pytest 55/55라고 보고하지만 각 테스트가 검증한 기능 목록은 제공하지 않습니다. Windows API pytest는 TestClient 초기화 단계에서 완료하지 못했고, 실제 HTTP API는 별도로 확인했다고 적혀 있습니다. Windows 방화벽 실제 적용·롤백도 아직 검증되지 않은 범위입니다. (13~14장)
